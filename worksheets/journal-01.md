# AI Decision Journal — Entry #1

**Question:** Does your domain system need an agent? Justify using the
decision matrix.

Half a page is enough. Answer about **components**, not the whole system.
"My system needs an agent" is not an answer. "Component 3 needs an agent with
tool use, by rule 2, because it has to query the live catalogue — the other
three do not" is.

---

## 1. Which components, which rules

> Copy the verdict column from your worksheet.

## 2. The decision

> Agent, no agent, or an agent in one component only?

## 3. The case against

> Three sentences arguing the other side. If you said yes, what would be
> simpler without it? If you said no, what are you giving up?

## 4. Autonomy check

> For anything you sent to "agent": what is the worst it could do if its
> planning loop went wrong, and would you find out?

## 5. One failure mode you saw in the live demo

> Name it: hallucinated tool call, scope drift, infinite loop, or silent
> failure. What was the first visible sign?
